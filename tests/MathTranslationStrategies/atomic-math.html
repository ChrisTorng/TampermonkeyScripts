MathJax SVG formula isolation test

This is an English article containing three inline equations in each long paragraph. Translate it into Traditional Chinese using Microsoft Edge's built-in Translate command.

In full comparison mode, first and second mean document order, not confirmed viewport exposure. Focus mode places a selected case near the top. Four distinct representations are repeated: original SVG nodes, atomic SVG images, Shadow DOM, and an embedded document iframe. None is guaranteed to work; this page is a diagnostic experiment. SVG export now disables MathJax 4 inline breaking to retain every term of each equation. Image cases start without visible TeX placeholders to avoid stale text being restored during delayed translation.

Disable any Tampermonkey page-translation or math-protection scripts before testing, especially Math Translation Guard 1.2.0. If a method works with scripts disabled, you can optionally compare with them enabled.
