方法與驗收解讀

比較原文、翻譯後、往下捲動後、回到頁頂後的變化。「公式順序正常」只是 DOM 層的必要條件，不能代替人工目視。整段不翻譯預期能保住公式，但不能算完成中文翻譯。

「模擬翻譯 API」是本頁內建、離線的固定中譯範本，不是真正翻譯服務。它會以公式佔位符生成新容器、保留原文 DOM，展示未來整合外部翻譯 API 時的資料流。不會把測試內容傳到任何翻譯伺服器。
