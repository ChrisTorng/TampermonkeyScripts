English Article: Inline Math and Browser Translation

This page uses KaTeX 0.19 / HTML+MathML and contains complete English paragraphs with three inline formulas each. Translate this page from English into Traditional Chinese using Microsoft Edge's built-in Translate command.

In full comparison mode, the first set is only first in document order; it may also require scrolling. For a genuine first-viewport trial, use Focus mode. The goal is to find formulas that disappear or move after the translation. A visible displayed equation is not proof that the inline equations survived. Four structural alternatives are included, each repeated once below the fold.

Before testing: Disable installed userscripts that change MathJax, translation, or DOM, especially Math Translation Guard 1.2.0, to isolate this engine. After the baseline, repeat with it enabled and compare.
