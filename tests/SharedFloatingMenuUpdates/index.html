Already installed? Enable Tampermonkey Dashboard → Settings → Userscript Update → Automatic installation to receive newer main versions without opening any install pages. Set a suitable Check Interval.

Testing an unmerged PR? Manual installation is still required. Do not use Reinstall just because an installed version is already current.

Open this update page directly in Microsoft Edge for Android (if your in-app browser allows app links). If this link is blocked, use your viewer's Open in external browser option.
